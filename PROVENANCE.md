# ARC provenance and event work

ARC is the team's existing company-workspace project, developed before the 3 November 2026 event opening. The clean public repository imported that foundation on 3 November; an import date does not establish the original creation date of every file. No claim is made that the whole application was created during this hackathon.

## Existing foundation

The Flutter chat and marketplace, CEO/department orchestration, deterministic company queue, human assignments/capacity, developer provider connections and restricted terminal design existed in the development workspace before kickoff. The original development history was not republished because it contained a revoked credential and bundled local environments. The sanitized source remains reviewable in this repository.

## Work completed during this event

- 3 November: publish a sanitized, reproducible source repository and CI.
- 5 November: deploy the frontend, central backend, persistent state, HTTPS proxy and native Linux terminal broker to a Vultr VM in Atlanta.
- Verify actual container restrictions, timeout cleanup, public API boundaries and provider replies on that VM.
- Persist repository connections over backend restarts; fix atomic terminal-grant permissions for the private Linux broker.
- Correct CEO greeting language, follow-up planning overhead and bounded retry handling for transient Gemini failures.
- Add MIT licensing, preserved dependency notices, release-license checks, current submission documentation and reproducible evidence.

See the public commit history for the exact changes and dates. Third-party libraries retain their own licenses. Project-specific concepts and implementation are ARC's; competitor submissions were reviewed only to assess presentation and evidence, not copied.
